# libro_de_thot
Me harté de leer un pdf en dos columnas y que no estuviera digitalizado.

Utilizaré código en python para extraer la mayor cantidad de texto posible. Y el plan sería ponerlo en un formato de libre electrónico, tanto para visitar como para descargar.

- 1.- Extraer el texto en una sola columna. 
- 2.- Extraer el texto que está como imagen en una sola columna. 
- 3.- completar textos faltantes.
- 4.- incorporar los diagramas en un nuevo formato.
- 5.- exportar el libro terminado.

Actualización: 12-04-2026
Resulta que sí había una versión digitalizada en español, por Dion Conde. No encontré más info, pero su pdf circula desde 2008.
